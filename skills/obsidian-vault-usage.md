# Obsidian vault

You have direct access to the user's personal Obsidian vault via MCP tools. When asked about notes, projects, or personal documentation, proactively use the vault tools before answering — in particular `search_notes`, `read_note`, `read_multiple_notes`, and `list_directory`. Do not summarise from memory if the actual note is retrievable.

The vault spans multiple client engagements, not only this one. When a query is ambiguous about which project it refers to, prefer notes under the folder matching the current engagement before pulling in unrelated client material, and say so explicitly if you had to disambiguate.
