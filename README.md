# local-openwebui-stack

Personal, fully local OpenWebUI + ChromaDB + mcpo stack backed by Ollama — no proprietary data leaves the machine.

See [`AGENTS.md`](./AGENTS.md) for architecture, setup, commands, and gotchas. It's the single source of truth for both human and AI-agent sessions (Claude Code, OpenCode, etc.) working in this repo.

**Quick start:** [First-time setup](./AGENTS.md#first-time-setup) in `AGENTS.md` — including copying `.env.example` to `.env` and filling in your customer/project/vault details — then `docker compose up -d`.
